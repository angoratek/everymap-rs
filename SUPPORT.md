# Support

If you need help with EveryMap-RS, here are your options:

- **Documentation**: Start with the [README](README.md) for an overview, and [TESTING.md](TESTING.md) for testing guidance.
- **Issues**: Search [existing issues](https://github.com/angoratek/everymap-rs/issues) before opening a new one.
- **Bug reports**: Open a [GitHub issue](https://github.com/angoratek/everymap-rs/issues/new) with a minimal reproduction.
- **Security vulnerabilities**: Email [security@angoratek.com](mailto:security@angoratek.com). Do not open a public issue. See [SECURITY.md](SECURITY.md).

For provider-specific API questions, refer to each provider's official documentation:

- [HERE Technologies API Docs](https://developer.here.com/documentation)
- [Google Maps Platform Docs](https://developers.google.com/maps/documentation)
- [TomTom Developer Portal](https://developer.tomtom.com/)
- [MapBox API Docs](https://docs.mapbox.com/api/)
- [Radar API Docs](https://radar.com/documentation/api)
